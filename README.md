# ฟอร์มเปิดลูกค้าใหม่ (Hi-Kool)

ฟอร์มสำหรับเซลส์กรอกข้อมูลลูกค้าใหม่ แล้วสร้างเอกสาร 2 ใบ
- ใบเปิดลูกค้าใหม่ (FP-SA-01-01)
- ใบขอเปิดบัญชีซื้อสินค้า (FP-SA-01-02)

ดาวน์โหลดเป็น Word (ตามแม่แบบ Word ของบริษัท) หรือ PDF (หน้าตาตรงกับแบบฟอร์ม PDF ต้นฉบับ) หรือสั่งพิมพ์ได้ ใช้ได้ทั้งในคอมและมือถือ

## วิธีใช้
เปิดลิงก์เว็บของ repository นี้ (ดูได้ที่ Settings → Pages) แล้วกรอกฟอร์มได้เลย

## ความเป็นส่วนตัว
ข้อมูลที่กรอกจะถูกเก็บไว้ในเบราว์เซอร์ของเครื่องที่กรอกเท่านั้น ไม่ถูกส่งขึ้นเว็บหรือเก็บใน repository นี้

## วิธีอัปเดตฟอร์ม
อัปโหลดไฟล์ `index.html` เวอร์ชันใหม่ทับไฟล์เดิม (Add file → Upload files) แล้วกด Commit changes
รอ 1–2 นาที ลิงก์เดิมจะเป็นเวอร์ชันใหม่
